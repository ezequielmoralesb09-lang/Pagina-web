# 🎮 GTA VI Fan Website

Sitio web dedicado a **Grand Theft Auto VI**, con información, trailers, personajes, mapa y recopilación de filtraciones y novedades.

## 📌 Contenido

* 🏠 Página principal
* 🎬 Trailers oficiales
* 👥 Personajes
* 🗺️ Mapa de Leonida
* 💻 Filtraciones de 2022
* 📰 Noticias y novedades
* 🔎 Información confirmada y rumores

## 🛠️ Tecnologías

* HTML
* CSS
* JavaScript

## ⚠️ Aviso

Este es un proyecto realizado por fans y **no está afiliado oficialmente con Rockstar Games** ni con Take-Two Interactive.

## 🎯 Objetivo

Crear un sitio informativo y visual sobre GTA VI, diferenciando entre información oficialmente confirmada, filtraciones y rumores.
